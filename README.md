# 美股 ETF 低吸高抛日报（us-etf-monitor）

每个美股交易日自动跑两次，生成一页手机可读的中文报告和一个自动跟单的模拟盘：

| 报告 | 美东时间 | 北京时间（冬令时） | 北京时间（夏令时） | 用途 |
|---|---|---|---|---|
| 盘中快照 | 10:30 | 23:30 | 22:30 | 睡前看开盘走势、跳空、放量 |
| 收盘定稿 | 16:30 | 次日 05:30 | 次日 04:30 | 起床看完整信号和「今晚操作清单」，开盘前挂单 |

> 本项目在开发环境里无法访问行情接口，全部流程用**模拟行情**跑通并有 21 项单元测试。
> 三个数据源的解析器按接口格式写好并有测试，**第一次真实联网运行请盯一下**（见第 5 节）。

---

## 1. 实现方案

### 1.1 ETF 池（`us_etf_monitor/config.py`）

分三档：10 只核心 → 20 只 → 30 只（上限）。赛道数量不追求均等，但每只都要好买好卖。

| 档 | ETF（代码） |
|---|---|
| 10 只 | 标普500 SPY、罗素2000小盘 IWM、美国红利 SCHD、黄金 GLD、中概互联 KWEB、半导体 SMH、金融 XLF、医疗保健 XLV、能源 XLE、可选消费 XLY |
| 20 只 | + 纳指100 QQQ、20年+美债 TLT、白银 SLV、日本 EWJ、德国 EWG、工业 XLI、公用事业 XLU、软件 IGV、生物科技 XBI、军工航天 ITA |
| 30 只 | + 综合商品 PDBC、金矿股 GDX、印度 INDA、韩国 EWY、必需消费 XLP、通信服务 XLC、房地产 XLRE、地区银行 KRE、铀与核电 URA、比特币 IBIT |

选池规则：

1. **同类去重**：每个赛道只留一只，取规模大、成交活跃、价差小、持仓与名称相符的。同赛道候选写在 `alts`（如 SMH 的候选是 SOXX）。
2. **成分优胜劣汰**：只选跟踪**规则化指数、定期调整成分**的 ETF，每只的指数和调仓规则写在 `index` / `recon` 两栏，报告里也能看到。例如：
   - 罗素2000（IWM）：2026 年起每年 6 月、12 月两次重构（[FTSE Russell](https://www.lseg.com/en/media-centre/press-releases/ftse-russell/2026/ftse-russell-announces-december-2026-russell-us-indexes-reconstitution-schedule)）
   - SCHD：每年 3 月按连续分红、现金流、ROE、股息率、股息增长重选 100 只
   - SMH：每年 3 月、9 月审核，半导体收入 ≥50% 才能入选（[MarketVector](https://www.marketvector.com/indexes/sector/mvis-us-listed-semiconductor-25)）
   - 行业 SPDR（XL 系列）：跟随标普500成分增删，每季度再平衡
3. **ETF 本身也优胜劣汰**：`pool_audit.py` 每月 1 号自动体检，规模 < 10 亿美元、日均成交 < 3000 万美元、价差 > 0.10% 的标红；同赛道候选的规模和成交额连续两个月都超过现任 1.5 倍，才建议替换（避免来回换）。还会列出前五大持仓，供人工核对“持仓与名称相符”。
4. **不入池**：杠杆/反向 ETF（长期有损耗），发 K-1 税表的合伙制基金（如 USO，海外投资者处理麻烦，用 PDBC 代替）。

### 1.2 每日指标（报告里每天都有）

| 你的要求 | 报告里怎么呈现 |
|---|---|
| RSI14 跌破 30 / 20 / 10 | 总览表每只都有 RSI14 数值 + 「破30/破20/破10」标签；RSI 排行条；左侧低吸卡片 |
| MA3/MA5/MA7 同步单边向上 + 放量 | 总览表「三线」箭头 + 量比；右侧启动卡片（连续 ≥2 天、MA3>MA5>MA7、量比 ≥1.2） |
| MACD 是否在 0 轴上方、是否金叉中期 | 总览表 MACD 列（上/下 · 金/死 · 第几天），0 轴上方金叉中期红色加粗 |
| MA 均线图形 | 每只一张近 60 日的收盘价 + MA5/MA20/MA60 小图，附多头/空头/缠绕判断、200 日线上下 |
| 当天各标的 RSI14 数值 | 总览表 + RSI 排行 |
| 距历史最高价、近 60 日最高价的跌幅 | 总览表「回撤」列（上：历史；下：60 日），左侧卡片也有 |
| 名词解释 | 页面最底部「术语解释」，含乖离、波动、高波动、量比、RS、ATR、VIX、200 日线、跳空、预扣税等 30 条 |

### 1.3 按美股规律设定的参数（与 A 股版的区别）

| 项目 | 美股版做法 | 原因 |
|---|---|---|
| 长期趋势线 | **200 日线**（A 股习惯 250 日年线） | 美股通用的牛熊分界 |
| 左侧分批 | 仍是破 30/20/10 三档，但**按波动分组配子弹**：低波动 50/30/20%，中波动 30/30/40%，高波动 20/30/50% | SPY、XLP 这类一年也难得跌破 RSI 20，子弹要放在第一档；半导体、比特币常跌得更深 |
| 追高判断 | 乖离 > **3 倍 ATR%** 才算过热 | 固定 8% 对 SPY 太宽、对铀 ETF 太严，用各自波动归一 |
| 价格口径 | **税后复权价**：拆股调整，分红扣 10% 预扣税后再投入 | 中国投资者真实到手的收益，红利类 ETF 的回撤也不会被高估 |
| 盘中量比 | 按美股 U 形成交分布折算（10:30 约占全天 19%） | 美股尾盘含收盘集合竞价，尾量更重 |
| 涨跌停 | 没有；跳空按开盘价成交，单独提示「开盘跳空 > 1.5 倍 ATR」 | 美股坏消息常在盘前消化，止损价不等于成交价 |
| 交易日历 | 纽交所日历（感恩节、圣诞休市，半天市 13:00 收盘） | `exchange_calendars` |
| 夏令时 | workflow 排两套 UTC 时间，程序按美东时间判断该不该跑 | GitHub 定时只认 UTC |
| 市场温度 | 原三项（站上 MA20 比例、平均 RSI、MACD 0 轴上方比例）+ **VIX 恐慌指数** | VIX > 30 恐慌时宽基左侧优先；< 13 警惕自满 |
| 宏观事件 | FOMC、CPI、非农日期写在 `events.py`；**事件前 2 个交易日右侧新开仓减半** | 美股三大事件当天波动常放大 |
| 成分调整日 | 罗素、纳指100、SCHD、SMH、标普季度再平衡自动列出 | 调整日前后常有异常成交 |
| 辅助短线信号 | RSI(2) < 10 且在 200 日线上方 → 进观察名单 | Connors 的经典美股短线规则，补低波动 ETF 很少触发 RSI14 < 30 的空白 |

### 1.4 策略：低吸高抛、周而复始

- **左侧低吸**：RSI14 新跌破一档就按该档比例加仓；200 日线下方减半、当前高波动再减半；反抽到 MA20 卖一半，剩下的保本 + 吊灯止盈线跟踪；10 个交易日站不回 MA5 认错。
- **右侧跟随**：三线同步向上 + 放量，启动 3 天内、不过热、RS 不在池内后 1/3 才跟；仓位按“跌到止损（收盘 − 2×ATR）最多亏总资金 1%”计算。
- **高抛**：RSI ≥ 80、涨后三线拐头、高位死叉各卖一半；跌破吊灯止盈线清仓。
- **总仓位**：跟市场温度走（冰点 100%、偏冷 90%、中性 80%、偏热 65%、过热 50%），日报和模拟盘同一张表。
- **今晚操作清单**：收盘报告顶部直接列出买/吸/抛、参考限价和止损，开盘前挂单即可。

### 1.5 模拟盘（`docs/sim.html`）

初始 10 万美元，单只上限 50%（高波动品种 25%）。收盘后决策、下一交易日开盘价成交；零佣金，卖出计监管费，滑点按档位 0.02%/0.02%/0.08%；最小 1 股。
同一套规则的 5 年历史回测（覆盖 2022 年股债双杀），和「买入 SPY 拿着」「60/40 股债」「池子等权持有」三条线对比，页面会直接写出结论：跑没跑赢 SPY、风险调整后划不划算。

## 2. 三分钟跑起来

```bash
pip install -r requirements.txt
python -m us_etf_monitor --demo --out docs   # 不联网，看版面：docs/index.html、docs/sim.html
python -m us_etf_monitor                     # 联网，真实行情（30 只），自动判断盘中/收盘
python -m us_etf_monitor --size 10           # 只看 10 只核心档；20 同理
python -m us_etf_monitor.pool_audit          # 池子体检：docs/pool.html
python -m pytest -q                          # 21 项单元测试
```

不在运行时段、休市或已出过同一时段报告时程序打印 `[skip]` 退出，不覆盖上一期；加 `--force` 可强制生成。

## 3. 每天自动运行（GitHub Actions，免费，不用开电脑）

1. 在 GitHub 新建一个**新仓库**（例如 `us-etf-monitor`），把本目录全部推上去（含 `.github/workflows/us-etf-monitor.yml`）。和原来的 A 股 `etf-monitor` 仓库完全独立。
2. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/docs`。
3. Actions 页面手动点一次「美股 ETF 日报」→ Run workflow（force 填 yes），确认能出报告。
4. 可选的 Secrets：
   - `FEISHU_WEBHOOK`：飞书群机器人地址，每次跑完推送摘要（标题带「美股」前缀）
   - `TIINGO_KEY`：[Tiingo](https://www.tiingo.com/) 免费 API key，Yahoo 被限频时的备用数据源（强烈建议加）
5. 报告地址 `https://<用户名>.github.io/us-etf-monitor/`，历史报告在 `/archive/`，池子体检在 `/pool.html`。

定时任务说明：workflow 排了 6 个 UTC 时间点（盘中 2 个、收盘 3 个、次日开盘前兜底 1 个），覆盖冬令时和夏令时，也给 GitHub 延误和数据源晚更新留了余地。程序按美东时间判断，不在时段内的、同一天同一时段已出过的都会跳过。

## 4. 数据源

| 顺序 | 数据源 | 说明 |
|---|---|---|
| 1 | Yahoo（yfinance） | 一次请求批量拉全部 30 只；本地缓存原始价 + 分红，之后每天只拉最近 10 天增量，减少被限频的机会 |
| 2 | Tiingo | 需要免费 key；给的是全额复权价，整段替换 |
| 3 | Stooq | 免费日线 CSV，最后兜底 |
| 4 | 本地缓存 | 全部失败时用上一版缓存，报告顶部会提示“数据过期” |

Yahoo 对云服务器 IP 限频较严（`YFRateLimitError`），所以程序做了批量 + 增量 + 重试退避，并建议配上 Tiingo key。

## 5. 首次真实运行检查

- 终端里有没有 `[warn]` / `[fatal]`；报告顶部有没有“数据提醒”。
- 随便挑 2 只，和富途/老虎/TradingView 对一下：RSI14（14）、MACD（12,26,9）、MA5。差 0.1 以内正常；
  历史高点会和软件略有差异，因为这里用的是**税后复权价**。
- 盘中量比的成交分布是估计值（`config.VOL_CURVE`），运行一个月后可用真实数据校准。
- 每年 1 月更新 `events.py` 里下一年的 FOMC、CPI、非农日期（美联储、BLS 官网每年提前公布）。

## 6. 目录

```
us_etf_monitor/
  config.py      ETF 池、全部参数（改池子、改阈值只动这里）
  data.py        数据源、缓存、税后复权、纽交所日历、演示数据
  indicators.py  RSI / MA / MACD / ATR / 乖离 / 回撤 / 量比 / RS
  signals.py     左侧 / 右侧 / 高抛 / 观察名单 / 市场温度 / VIX / 智囊团规则
  events.py      FOMC、CPI、非农、指数成分调整日历
  report.py      日报 HTML（手机优先，红涨绿跌）
  sim.py         模拟盘 + 5 年回测 + 收益看板
  pool_audit.py  月度池子体检（ETF 层面的优胜劣汰）
tests/           21 项单元测试（不联网）
REVIEW.md        三轮复盘与优化记录
```

本项目只做信息整理和规则检验，不构成投资建议；税务说明仅供参考，以券商和税务顾问为准。
