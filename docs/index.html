术语解释

RSI14（相对强弱指标）
衡量最近14个交易日涨跌力度的0~100读数。低于30叫超卖（跌得急，容易反抽），低于20、10更极端；高于70叫超买（涨得急，容易回落）。
左侧 / 右侧
左侧：还在跌的时候分批买，赌反抽，买得便宜但可能继续跌。右侧：等涨势确认后再跟，买得贵一点但方向更明确。
低 / 中 / 高波动品种
按这只ETF近一年平均每天的波动（ATR%中位数）分组：低于1.2%算低波动（如SPY、必需消费），高于2.5%算高波动（如半导体、比特币）。低波动品种跌破RSI 30就很少见，所以第一档买得多；高波动品种常常跌得更深，子弹留到后面。
MA（均线）
最近N天收盘价的平均值。MA3、MA5、MA7看短线方向；MA20看一个月趋势；MA60看一个季度。
200日线
最近200个交易日的平均价，美股最常用的牛熊分界线。价格在它上方的回调更值得买，在它下方的超卖可能是“下跌中继”，所以本报告的左侧仓位在线下减半。
三线同步向上
MA3、MA5、MA7今天都比昨天高。本报告还要求MA3>MA5>MA7且连续至少2天，才算右侧信号的均线条件。
多头排列 / 空头排列
短期均线在上、长期均线在下且一起向上，是多头排列（上升趋势）；反过来是空头排列（下降趋势）。互相缠在一起叫均线缠绕（震荡）。
量比
今天成交量 ÷ 过去5天平均成交量。大于1.2算温和放量，大于1.5算明显放量。盘中报告已按美股U形成交分布折算成全天。
MACD
由两条线组成的趋势指标：快线DIF、慢线DEA。两条线都在0上方（0轴上方）说明中期趋势向上。
金叉 / 死叉 / 金叉中期
DIF向上穿过DEA叫金叉，向下穿过叫死叉。本报告把金叉后第1~3天叫初期，第4~10天叫中期（趋势走出来了但还没走老），10天以上叫后期。
动能增强 / 减弱
MACD红绿柱（DIF与DEA的差距）比昨天变长还是变短。变短说明这段走势在减速。
乖离（BIAS）
现价偏离20日均线的百分比。本报告用“乖离是ATR%的几倍”来判断追高风险，超过3倍提示别追：SPY乖离3%就很极端，铀ETF乖离9%才算。
波动 / 波动率
价格上下起伏的剧烈程度。报告里的波动率是按最近20天日涨跌幅折算的年化数字，越大越颠簸。
ATR / ATR%
平均真实波幅：最近14天平均每天上下波动多少美元。ATR%是它占现价的比例，例如2%表示平均每天波动2%。用来定止损距离和仓位。
高波动（当前）
当前ATR%处在这只ETF自己近一年的前20%高位。这时同样仓位风险更大，仓位减半。
RS（相对强弱）
这只ETF最近20天的涨幅，减去标普500ETF（SPY）同期涨幅。正数说明比大盘强；排名是在本池内从强到弱的名次。注意它和RSI不是一回事。
回撤（距高点跌幅）
现价比某个最高价低了百分之多少。距历史高点用数据里最早到今天的最高价，距60日高点用最近60个交易日的最高价。
税后复权价
把拆股和分红造成的价格跳变抹平后的价格，分红按扣掉10%预扣税后再投入计算，这样不同时期的价格可比，也贴近中国投资者真实到手的收益。
跳空
今天开盘价和昨天收盘价之间的缺口。美股没有涨跌停，坏消息常在盘前消化，开盘可能直接跌穿你的止损价，所以止损价不等于成交价。
吊灯止盈线
最近22天最高价减去3倍ATR。价格涨它跟着抬，价格跌它不动；收盘跌破就离场，用来保护右侧单的利润。
止损
买入前就定好的认错价位。本报告右侧信号的初始止损 = 买入价 − 2倍ATR。
仓位%
建议这只ETF占你总资金的比例。算法：单笔最多亏总资金的1%，再除以止损距离，且单只不超过20%。
市场温度 / 参考总仓位上限
综合池内站上20日线的比例、平均RSI、MACD在0轴上方的比例得到的0~100分。低于20冰点，高于80过热。越冷允许的总仓位越高，是逆向思路的粗略参考。
VIX（恐慌指数）
由标普500期权价格算出的市场预期波动率。低于13偏平静（容易自满），20~30紧张，30以上恐慌。恐慌时往往是分批买宽基的时机。
FOMC / CPI / 非农
美联储利率会议、通胀数据、就业数据，美股三大宏观事件，发布当天波动常常放大。本报告在事件前2个交易日把右侧新开仓减半。
成分调整（优胜劣汰）
指数按固定规则定期剔除不达标的公司、纳入新达标的公司，ETF跟着调仓。比如罗素2000每年6月、12月重构，SCHD每年3月按分红质量重选100只。本池只选这类规则化指数ETF。
规模 / 日均成交额 / 买卖价差
规模越大越不容易清盘；日均成交额越大越容易买进卖出；买卖价差是买一和卖一之间的差，越小交易成本越低。本池门槛：规模10亿美元以上、日均成交3000万美元以上。
相关性 / 高度同向
两只ETF最近60天涨跌同步的程度，1为完全同步。高于0.8时同时买两只等于重复下注，只做其中更强的一只。
预扣税 / W-8BEN
非美国人持有美国ETF，分红会先被代扣税。在券商填写W-8BEN表后，中国税务居民一般按中美税收协定扣10%。不构成税务建议。
历史表现（胜率）
这只ETF历史上同一信号首次出现后，持有10个交易日的结果统计。次数少于5次时参考价值很低。
